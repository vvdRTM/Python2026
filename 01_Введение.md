## Краткая теория

Переменная — имя, связанное со значением. Операция `=` присваивает значение, а не сравнивает его. Тип определяется значением; заранее объявлять тип переменной не нужно.

| Тип | Пример | Назначение |
|---|---|---|
| `str` | `"Анна"` | Текст |
| `int` | `18` | Целое число |
| `float` | `2.5` | Число с плавающей точкой |
| `bool` | `True` | Логическое значение |

`input()` возвращает строку. Для вычислений преобразуйте её через `int()` или `float()`. Для дробного числа при вводе используйте точку: `2.5`. `print()` выводит значения. F-строка подставляет выражения на место фигурных скобок.

```python
# example.py
name = input("Как вас зовут? ")
age = int(input("Сколько вам лет? "))
print(f"Привет, {name}!")
print(f"Через год вам будет {age + 1}.")
```

При вводе `Маша` и `17` последние две строки: `Привет, Маша!` и `Через год вам будет 18.`

Комментарий начинается с `#` вне строкового литерала. Он может находиться после кода: `name = "Маша"  # имя`. Используйте имена `age`, `city`, `study_hours`, не называйте переменные `input`, `print` или `int`.

### Как читать ошибку

В сообщении об ошибке найдите имя файла, номер строки и последнюю строку с типом ошибки. `SyntaxError` обычно означает ошибку записи кода, `NameError` — неизвестное имя, `ValueError` при `int()` — строку, которую нельзя преобразовать в целое число. `TypeError` возникает при операции с неподходящими типами, например при сложении строки и целого числа.

### Вычисления и оформление

Операции `+`, `-`, `*`, `/` выполняют сложение, вычитание, умножение и деление. Сначала выполняются умножение и деление, затем сложение и вычитание; скобки задают другой порядок. Делитель не должен быть равен нулю.

```python
quantity = 3
price = 12.5
cost = quantity * price
print(f"Стоимость: {cost:.2f} руб.")  # Стоимость: 37.50 руб.
print("Название", "Количество", "Стоимость", sep=" | ")
```

`:.2f` выводит два знака после точки. Параметр `sep` задаёт разделитель между аргументами `print()`. Вызов `type(value)` позволяет узнать тип значения. Все вычисляемые показатели нужно получать из входных данных, а не подставлять готовыми числами.

В `debug.py` исправьте три независимых фрагмента. Перед исправлением запишите ожидаемый результат или причину ошибки. В исправленном файле каждый фрагмент должен выполняться, а результаты должны иметь подписи.

Фрагмент А: требуется сумма чисел `5`, а не соединение строк `23`.


Фрагмент Б: требуется возраст через год. Ввод для проверки — `17`. Ниже приведён намеренно ошибочный код.

Фрагмент В: требуется среднее трёх чисел `4`, `7`, `10`; правильный результат — `7.0`.


Объясните каждое исправление. Для фрагментов А и Б выведите типы значений до и после преобразования.

### 4. Обмен значениями
