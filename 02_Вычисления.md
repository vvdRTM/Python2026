## Цель

Переводить условие задачи в арифметическое выражение, выбирать тип данных, проверять ответ вручную. Необходимы ввод, вывод и преобразование типов из работы №1.

## Краткая теория

| Выражение | Действие | Пример |
|---|---|---|
| `a + b`, `a - b` | Сложение, вычитание | `7 - 2 == 5` |
| `a * b` | Умножение | `3 * 4 == 12` |
| `a / b` | Деление | `7 / 2 == 3.5` |
| `a // b` | Деление с округлением вниз | `7 // 2 == 3`, `-7 // 2 == -4` |
| `a % b` | Остаток | `7 % 2 == 1` |
| `a ** b` | Степень | `2 ** 3 == 8` |
| `abs(a)` | Модуль | `abs(-5) == 5` |

Делитель не должен быть равен нулю. Для целых `a`, `b` при `b != 0` выполняется равенство `a == (a // b) * b + a % b`. Скобки позволяют явно задавать порядок вычислений. Степень выполняется раньше умножения, умножение и деление — раньше сложения.

`float` хранит многие дроби приближённо. Например, `0.1 + 0.2` может выглядеть как `0.30000000000000004`. Формат `:.2f` задаёт два знака при выводе, но не меняет хранимое число. В задачах о деньгах этого курса используйте целое количество рублей или копеек, как указано в условии.

Модуль — файл с готовыми функциями и другими объектами. Модуль `math` входит в стандартную библиотеку и не требует отдельной установки.

```python
# example.py
import math

width = float(input("Ширина прямоугольника: "))
height = float(input("Высота прямоугольника: "))
diagonal = math.sqrt(width ** 2 + height ** 2)
print(f"Диагональ: {diagonal:.2f}")
```

При ширине `3` и высоте `4` результат: `Диагональ: 5.00`. Здесь стороны положительные. `math.sqrt(x)` требует `x >= 0`. `math.ceil(x)` — наименьшее целое, не меньшее `x`; `math.floor(x)` — наибольшее целое, не большее `x`. Углы в тригонометрических функциях `math` задаются в радианах.

## Обязательные задания

### 1. Перевод времени

В `time_parts.py` введите целое `total_seconds >= 0`. Выведите количество полных часов, оставшихся минут и секунд. Часы могут превышать 23.

Пример: `3671` → `1 ч 1 мин 11 с`. Используйте `//` и `%`, без библиотек времени.

### 2. Стоимость покупки

В `purchase.py` введите цену одной тетради в целых рублях `price >= 0`, количество `count >= 0` и переданную сумму `paid`. Гарантируется `paid >= price * count`. Выведите стоимость и сдачу. Например, `price=45`, `count=3`, `paid=200` → стоимость `135`, сдача `65`.

### 3. Предскажите результат

До запуска вычислите вручную `2 + 3 * 4`, `(2 + 3) * 4`, `17 // 5`, `17 % 5`, `-7 // 2`. Запишите прогноз, затем результат Python в README. Объясните различия, если они появились.
