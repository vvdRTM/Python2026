# План курса

Курс включает 12 лабораторных работ: от ввода и вывода данных до приложения с сохранением записей в JSON. Рекурсия рассматривается в дополнительном задании работы №9, графический интерфейс — работы №12.

| № | Лабораторная работа | Что вы научитесь делать |
|---|---|---|
| 1 | [Первые программы](01_Введение.md) | Сохранять и запускать код, вводить и выводить данные |
| 2 | [Вычисления](02_Вычисления.md) | Использовать арифметические операции и проверять результат |
| 3 | [Условия](03_Условия.md) | Выбирать действия с помощью логических выражений |
| 4 | [Циклы](04_Циклы.md) | Повторять действия, считать количество и сумму |
| 5 | [Строки](05_Строки.md) | Нормализовать текст, искать и заменять подстроки |
| 6 | [Списки](06_Списки.md) | Хранить, фильтровать и сортировать наборы значений |
| 7 | [Функции и проверки](07_Функции.md) | Разделять программу на функции и проверять их |
| 8 | [Словари, множества, кортежи](08_Коллекции.md) | Представлять записи и подсчитывать частоты |
| 9 | [Вложенные списки](09_Таблицы.md) | Обрабатывать прямоугольные таблицы |
| 10 | [Файлы и исключения](10_Файлы.md) | Читать и сохранять данные, обрабатывать ошибки |
| 11 | [JSON и HTTP](11_JSON_HTTP.md) | Обмениваться структурированными данными |
| 12 | [Итоговый проект](12_Проект.md) | Собрать и защитить законченное приложение |
