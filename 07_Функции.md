## Цель

Разделять вычисления и взаимодействие с пользователем, передавать параметры, возвращать результат и проверять поведение функций. Необходимы работы №1–6.

## Краткая теория

`def` создаёт функцию. Параметры — имена в её определении; аргументы — значения при вызове. `return` завершает текущий вызов и возвращает результат. Функция без явного возвращаемого значения возвращает `None`; отдельной конструкции «процедура» в Python нет.

```python
# example.py
def rectangle_area(width, height):
    """Вернуть площадь; стороны должны быть неотрицательными."""
    return width * height


assert rectangle_area(3, 4) == 12
assert rectangle_area(0, 5) == 0
print(rectangle_area(2, 6))  # 12
```

Переменные внутри функции обычно локальны. Передавайте нужные данные параметрами, а результат возвращайте через `return`; для этих заданий `global` не нужен. `print()` показывает результат человеку, но не заменяет возвращаемое значение.

`assert condition` ничего не выводит при истинном условии и вызывает `AssertionError` при ложном. Здесь `assert` используется для учебных проверок функций. Проверку пользовательского ввода строят через условия и исключения, а не через `assert`: при оптимизированном запуске проверки `assert` могут быть отключены.

### Модуль и точка входа

Сохранённый `.py`-файл можно импортировать по имени без расширения. Код под условием ниже выполняется при прямом запуске файла, но не при его импорте:

```python
# main_example.py
def double(number):
    return number * 2


def main():
    number = int(input("Целое число: "))
    print(double(number))


if __name__ == "__main__":
    main()
```

## Обязательные задания

Создайте `functions.py`. Следующие функции не должны вызывать `input()` или `print()`.

1. `sum_digits(number)` принимает любое целое, возвращает сумму цифр его модуля. Для нуля результат `0`. Используйте цикл и целочисленную арифметику. Сначала получите `abs(number)`, иначе отрицательное число может не приблизиться к нулю при `// 10`.
2. `average(numbers)` принимает список чисел, возвращает среднее либо `None`, если список пуст. Исходный список не изменяется.
3. `normalize_text(text)` возвращает строку в нижнем регистре, без пробельных символов по краям и с одним пробелом между словами. Используйте правила работы №5.

В `main.py` продемонстрируйте все три функции: запросите целое число, строку чисел и произвольный текст. Для пустого списка вместо среднего выведите `Нет данных`.

## Проверки

Создайте `test_functions.py` рядом с модулем. Начальный набор:

```python
from functions import average, normalize_text, sum_digits

assert sum_digits(0) == 0
assert sum_digits(507) == 12
assert sum_digits(-507) == 12
assert average([]) is None
assert average([2, 4, 6]) == 4
assert normalize_text("  ПРИВЕТ   Мир  ") == "привет мир"
assert normalize_text("   ") == ""
print("Базовые проверки пройдены")
```

Дополните файл проверками своего варианта:

- Вход `[-5, 0, 2, 5]`, порог `2`: вариант 1 → `[5]`; вариант 2 → `[-5, 0]`; вариант 3 → `[-5, 5]`.
- Пустой список → `[]`.
- Проверьте значения на границе условия и рядом с ней. Включение границы определяется условием вашего варианта. Для варианта 15 при пороге 0 совпадений нет.
- Повторы подходящего значения сохраняются.
- Исходный список после вызова равен заранее сохранённой копии.

Для проверки дробного среднего можно сравнивать `abs(actual - expected) < 1e-9`. Запустите `python test_functions.py`. Затем намеренно внесите одну ошибку в функцию, убедитесь, что проверка её обнаружила, и верните исправную версию.
