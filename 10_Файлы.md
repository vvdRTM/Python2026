## Цель

Читать и сохранять текст в UTF-8, проверять формат данных, обрабатывать ожидаемые ошибки без потери исходного файла. Необходимы работы №1–9.

## Краткая теория

`open()` открывает файл. Для текста курса явно задавайте `encoding="utf-8"`.

| Режим | Назначение |
|---|---|
| `r` | Чтение; файл должен существовать |
| `w` | Запись; создаёт файл или стирает прежнее содержимое |
| `a` | Добавление в конец; создаёт отсутствующий файл |

`with` закрывает открытый файл при выходе из блока, в том числе при возникновении исключения внутри блока. `read()` читает всё оставшееся содержимое, `readline()` — следующую строку, `readlines()` — список оставшихся строк. Аргумент `readlines(hint)` задаёт ориентир объёма чтения, а не номер строки. Для построчной обработки используйте `for line in file`.

```python
# file_example.py
from pathlib import Path

folder = Path(__file__).resolve().parent
source = folder / "notes.txt"
with open(source, "w", encoding="utf-8") as file:
    file.write("Python\nФайлы\n")

with open(source, "r", encoding="utf-8") as file:
    for line in file:
        print(line.rstrip("\n"))
```

Пример создаёт или перезаписывает `notes.txt` рядом со скриптом и выводит две строки. `Path(__file__).resolve().parent` задаёт папку скрипта; простой относительный путь считается от текущей рабочей папки запуска.

### Исключения

```python
# error_example.py
try:
    number = int(input("Введите целое: "))
except ValueError:
    print("Нужно ввести целое число")
else:
    print(number * 2)
```

`try` содержит операцию, которая может завершиться ошибкой. `except` обрабатывает указанный тип. `else` выполняется, если блок `try` завершился без исключения. Для отсутствующего файла используется `FileNotFoundError`, для ряда ошибок доступа — `OSError`, для неправильной кодировки — `UnicodeError`. Не скрывайте все ошибки через пустой `except`.

Для собственной проверки можно вызвать исключение: `raise ValueError("Строка 2: ожидалось 3 числа")`. Функция чтения сообщает о проблеме исключением, а основная программа показывает понятное сообщение.

## Обязательные задания

### 1. Надёжный ввод размера

В `main.py` реализуйте `read_positive_integer()`: повторяйте ввод, пока не получено целое число больше нуля. Различайте сообщения «не целое число» и «должно быть больше нуля». Проверьте последовательность `abc`, `0`, `-2`, `3`.

### 2. Чтение таблицы

В `files_lab.py` реализуйте `read_matrix(path)`. Формат файла:

- Первая строка: два положительных целых числа — количество строк и столбцов.
- Далее ровно указанное количество строк, в каждой ровно указанное количество целых чисел.
- Лишние и пустые строки считаются ошибкой. Один обычный перевод строки после последней строки данных допустим.
- При ошибке формата выбрасывайте `ValueError` с понятным пояснением и номером строки, если он применим.

Сохраните `matrix.txt` в UTF-8:

```text
2 3
1 -2 3
4 0 -6
```

Верните список `[[1, -2, 3], [4, 0, -6]]`. Пустой файл, неверный заголовок, нечисловая ячейка и неправильное количество строк должны обнаруживаться.

### 3. Отчёт

Скопируйте из работы №9 модуль `table.py` рядом с новыми файлами. В `main.py` прочитайте `matrix.txt`, найдите суммы строк и столбцов и только после успешной проверки всех данных запишите `report.txt`.

Пример содержимого отчёта:

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
```

В основной программе обработайте отсутствие файла, неверный формат, кодировку и ошибки файлового доступа. При ошибке чтения или проверки входа существующий `report.txt` должен остаться без изменений. Входной файл никогда не открывайте в режиме записи.

## Проверки

В `test_files.py` используйте `tempfile.TemporaryDirectory()`, чтобы проверки создавали файлы в отдельной временной папке:

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from files_lab import read_matrix

with TemporaryDirectory() as directory:
    path = Path(directory) / "matrix.txt"
    path.write_text("1 2\n7 -1\n", encoding="utf-8")
    assert read_matrix(path) == [[7, -1]]
print("Проверка чтения пройдена")
```

Добавьте проверки:

| Содержимое или ситуация | Ожидаемое поведение |
|---|---|
| `1 1` и строка `0` | Матрица `[[0]]` |
| Пустой файл | `ValueError` |
| Заголовок `0 3` | `ValueError` |
| Заголовок `1 2`, строка `1` | `ValueError` с указанием строки 2 |
| Заголовок `1 2`, строка `1 x` | `ValueError` с указанием строки 2 |
| Заголовок `1 1`, две строки данных | `ValueError` |
| Отсутствующий путь | `FileNotFoundError` в функции, сообщение в основной программе |

Для проверки ожидаемого исключения используйте `try`/`except ValueError`; в ветви `else` выполните `assert False, "Ошибка не обнаружена"`. Отдельно вручную проверьте сохранность старого отчёта при некорректном входе и запишите результат в README.
