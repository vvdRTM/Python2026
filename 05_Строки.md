## Цель

Обрабатывать текст с помощью индексов, срезов, методов и циклов; заранее определять правила сравнения текста. Необходимы работы №1–4.

## Краткая теория

Строка `str` — неизменяемая последовательность символов. Индекс первого символа — `0`, последнего — `-1`. Обращение по индексу к пустой строке вызывает ошибку, а срез пустой строки допустим.

| Выражение | Результат или действие |
|---|---|
| `len(text)` | Количество символов |
| `text[start:stop]` | Срез; правая граница не включается |
| `text[::-1]` | Строка в обратном порядке |
| `text.strip()` | Новая строка без пробельных символов по краям |
| `text.lower()` | Новая строка в нижнем регистре |
| `text.replace(old, new)` | Замена всех вхождений подстроки |
| `text.count(part)` | Количество неперекрывающихся вхождений |
| `part in text` | Есть ли подстрока |
| `text.split()` | Список слов, разделённых пробельными символами |
| `" ".join(words)` | Соединение строк через пробел |

Список подробно изучим в работе №6. Пока достаточно знать, что результат `split()` можно перебирать циклом `for word in words` и передавать в `len()` и `join()`.

```python
# example.py
text = input("Введите текст: ")
normalized = " ".join(text.lower().split())
print(normalized)
print(f"Слов: {len(normalized.split())}")
```

При вводе `  Python   И  ДАННЫЕ  ` результат: `python и данные`, слов `3`. Вызов `text.lower()` сам по себе не изменяет `text`: результат нужно использовать или присвоить.

## Обязательные задания

### 1. Нормализация текста

В `normalize.py` удалите пробельные символы по краям введённой строки и замените последовательности пробельных символов внутри одним пробелом. Регистр сохраните. Выведите исходную и новую длину, нормализованный текст и количество слов. В этой задаче слово — непустая часть, полученная через `split()`; знаки препинания остаются частью слова.

### 2. Палиндром

В `palindrome.py` проверьте текст на палиндром. Правила: игнорировать регистр и обычные пробелы `" "`; остальные символы, включая пунктуацию, сравнивать как есть. Если после очистки строка пуста, вывести `Нет текста`, иначе `Палиндром` или `Не палиндром`. Используйте срез `[::-1]`.

Если дополнительно решаете задачу циклом, обходите половину длины **очищенной** строки, а не исходной.

### 3. Замена с подсчётом

В `replace.py` замените все двоеточия на дефисы и выведите количество замен и новую строку. Сначала подсчитайте вхождения в исходном тексте, затем выполните замену.

## Индивидуальный вариант

В `variant.py` введите строку. Разбейте её по пробельным символам. Для каждого полученного слова удалите с обоих краёв символы `.,!?;:` через `word.strip(".,!?;:")` и переведите в нижний регистр. Пустые результаты пропускайте. Выведите каждое подходящее очищенное слово на отдельной строке и общее количество. Повторы сохраняйте. Если подходящих слов нет, выведите `Нет совпадений` и количество `0`.

Контрольный текст для таблицы: `Анна, армия! Я читаю. Книга, край, рама.`. Количество совпадений равно числу слов в последнем столбце.

| Вариант | Условие | Подходящие слова в примере |
| --- | --- | --- |
| 1 | Начинается с `а` | анна, армия |
| 2 | Заканчивается на `я` | армия, я |
| 3 | Длина не меньше 5 | армия, читаю, книга |
| 4 | Начинается с `к` | книга, край |
| 5 | Заканчивается на `а` | анна, книга, рама |
| 6 | Длина равна 4 | анна, край, рама |
| 7 | Содержит букву `р` | армия, край, рама |
| 8 | Содержит ровно одну букву `а` | армия, читаю, книга, край |
| 9 | Не содержит букву `а` | я |
| 10 | Начинается и заканчивается одной буквой | анна, я |
| 11 | Длина от 3 до 5 включительно | анна, армия, читаю, книга, край, рама |
| 12 | Содержит подстроку `ра` | край, рама |
| 13 | Заканчивается на `й` | край |
| 14 | Длина чётная | анна, край, рама |
| 15 | Начинается с гласной из строки `аеёиоуыэюя` | анна, армия, я |

Для проверки начала и конца используйте `startswith()` и `endswith()`. Например, `"анна".startswith("а")` возвращает `True`. Для подсчёта буквы используйте `count()`, для проверки вхождения — `in`. Обращайтесь к первому и последнему символу только после пропуска пустых слов.

## Проверки

- Нормализация: `  Один   два  ` → `Один два`, слов `2`, длина результата `8`; пустая строка → длина `0`, слов `0`.
- Палиндром: `А роза упала на лапу Азора` → да; `а    ` → да; строка из пробелов → `Нет текста`; `Python` → нет; `А!` → нет по принятым правилам.
- Замена: `a::b:` → `a--b-`, замен `3`; `abc` → без изменений, замен `0`.
- Вариант, текст `Анна, армия! Я читаю.`: вариант 1 → `анна`, `армия`, количество `2`; вариант 2 → `армия`, `я`, количество `2`; вариант 3 → `армия`, `читаю`, количество `2`.
- Для варианта дополнительно проверьте пустой ввод и строку `!!!`.
