## Цель

Создавать списки, обходить и изменять их, фильтровать значения и сохранять исходные данные. Необходимы работы №1–5.

## Краткая теория

`list` — изменяемая упорядоченная последовательность объектов. Элементы могут иметь разные типы, но в этой работе используем списки целых чисел.

```python
# example.py
numbers = []
for part in input("Целые числа через пробел: ").split():
    numbers.append(int(part))

positive = []
for number in numbers:
    if number > 0:
        positive.append(number)

print(f"Исходный список: {numbers}")
print(f"Положительные: {positive}")
```

Ввод `-2 0 5 3` даёт исходный список `[-2, 0, 5, 3]` и результат `[5, 3]`. Пустая строка даёт пустой список.

| Операция | Смысл |
|---|---|
| `items.append(value)` | Добавить один элемент в конец |
| `items[i] = value` | Заменить существующий элемент |
| `items.pop(i)` | Удалить и вернуть элемент по индексу |
| `len(items)`, `sum(items)` | Длина и сумма |
| `min(items)`, `max(items)` | Минимум и максимум непустого списка |
| `items.copy()` | Поверхностная копия |
| `sorted(items)` | Новый отсортированный список |
| `items.sort()` | Изменение порядка в исходном списке; возвращает `None` |
| `enumerate(items)` | Пары «индекс, значение» для обхода |

Запись `copy = items` связывает два имени с одним списком. Для плоского списка чисел достаточно `items.copy()`, чтобы менять копию независимо. Вложенные списки рассмотрим в работе №9.

Списковое включение — краткая запись построения списка: `[number * 2 for number in numbers]`. Сначала освойте эквивалентный цикл с `append()`.

## Обязательные задания

### 1. Статистика

В `statistics.py` введите целые числа одной строкой. Выведите количество, сумму, минимум, максимум и среднее с двумя знаками после точки. Если ввод пустой, выведите только `Нет данных`; не вызывайте `min()` или `max()` и не делите на ноль.

### 2. Независимое преобразование

В `transform.py` создайте новый список, заменив отрицательные числа их модулями. Выведите исходный и новый списки. Исходный список должен сохраниться. Пустой ввод допустим.

### 3. Позиции максимума

В `positions.py` найдите все индексы максимального элемента в порядке возрастания. Например, `3 7 2 7` → `[1, 3]`. Для пустого списка выведите `Нет данных`. После определения максимума используйте обход с `enumerate()`.

## Проверки

- Статистика: `-2 0 5 3` → количество `4`, сумма `6`, минимум `-2`, максимум `5`, среднее `1.50`.
- Статистика: `8` → все показатели, кроме количества, равны `8` или `8.00`; пустой ввод → сообщение.
- Преобразование: `-2 0 5 -2` → новый `[2, 0, 5, 2]`, исходный `[-2, 0, 5, -2]`.
- Позиции: `7 7` → `[0, 1]`; `-3 -1 -2` → `[1]`.
- Вариант, ввод `-8 -3 0 6 6 1`: вариант 1 → `[-8, 0, 6, 6]`, количество `4`, сумма `4`; вариант 2 → `[-8, -3]`, количество `2`, сумма `-11`; вариант 3 → `[-8, 6, 6]`, количество `3`, сумма `4`.
- Для варианта проверьте также пустой ввод и ввод без совпадений.
