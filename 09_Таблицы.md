## Цель

Обрабатывать прямоугольную таблицу вложенными циклами, различать строки и столбцы, не создавать общие изменяемые строки случайно. Необходимы работы №1–8.

## Краткая теория

Таблица представлена списком строк. В `matrix[row][column]` первый индекс задаёт строку, второй — столбец. Например, `[[1, 2, 3], [4, 5, 6]]` содержит две строки и три столбца.

```python
# example.py
rows = 2
columns = 3
matrix = [[0] * columns for _ in range(rows)]
matrix[0][0] = 7

for row in matrix:
    print(*row)
```

Результат: первая строка `7 0 0`, вторая `0 0 0`. `print(*row)` передаёт элементы строки отдельными аргументами `print`. Символ `_` — обычное имя переменной, которое здесь показывает, что её значение не используется.

Не создавайте таблицу как `[[0] * columns] * rows`: все элементы внешнего списка будут ссылаться на один внутренний список. Изменение одной ячейки затронет несколько строк. `matrix.copy()` копирует только внешний список. Для независимой копии таблицы чисел используйте `[row.copy() for row in matrix]`.

### Ввод прямоугольной таблицы

```python
# input_example.py
rows = int(input("Количество строк: "))
columns = int(input("Количество столбцов: "))
matrix = []
for _ in range(rows):
    row = [int(part) for part in input("Строка таблицы: ").split()]
    while len(row) != columns:
        print(f"Нужно ровно {columns} чисел")
        row = [int(part) for part in input("Повторите строку: ").split()]
    matrix.append(row)
print(matrix)
```

В этом примере размеры положительные, ввод содержит только целые числа. Для вычислений важно использовать реальную длину строки, а не предполагать квадратную таблицу.

## Проверки

## Дополнительный модуль: рекурсия

Рекурсивная функция вызывает саму себя. Нужны базовый случай и шаг, приближающий к нему. Это отдельный способ описания алгоритма, а не обязательная оптимизация циклов.

```python
# recursion_example.py
def factorial(number):
    """Аргумент — целое число от 0 до 20."""
    if number == 0:
        return 1
    return number * factorial(number - 1)


assert factorial(0) == 1
assert factorial(5) == 120
```

Постройте трассировку `factorial(3)`: вызовы с `3`, `2`, `1`, `0`, затем возвраты `1`, `1`, `2`, `6`. Реализуйте итеративную версию и сравните результаты для чисел 0–20. Не увеличивайте предел глубины рекурсии: слишком глубокая цепочка вызовов вызывает `RecursionError`.

Справка: [вложенные списковые включения](https://docs.python.org/3/tutorial/datastructures.html#nested-list-comprehensions).
