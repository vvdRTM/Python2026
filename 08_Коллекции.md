## Цель

Выбирать структуру данных для записи, уникальных значений и пар; обрабатывать список словарей. Необходимы работы №1–7.

## Краткая теория

| Тип | Для чего нужен | Пример |
|---|---|---|
| `list` | Последовательность с повторами | `["Python", "Python", "SQL"]` |
| `dict` | Соответствие ключей значениям | `{"title": "Python", "hours": 4}` |
| `set` | Уникальные элементы, операции над множествами | `{"Python", "SQL"}` |
| `tuple` | Неизменяемая последовательность, например пара | `("Python", 4)` |

В этой работе ключи словаря — строки. Чтение `record["title"]` требует существующего ключа; `record.get("hours", 0)` возвращает значение либо указанный запасной результат. Присваивание по существующему ключу заменяет значение. Пустое множество создаётся через `set()`, поскольку `{}` — пустой словарь.

У множества нет индексов и гарантированного порядка вывода. Для воспроизводимого результата используйте `sorted(values)`. Операции: `a & b` — пересечение, `a | b` — объединение, `a - b` — разность.

```python
# example.py
words = "python sql python".split()
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

for word in sorted(counts):
    print(f"{word}: {counts[word]}")

pair = ("python", counts["python"])
name, count = pair
print(f"Пара: {name}, {count}")
```

Результат: `python: 2`, `sql: 1`, `Пара: python, 2`. Перебор `for key, value in dictionary.items()` тоже использует распаковку пары.

### 3. Запись и пара

Создайте словарь с ключами `title` и `hours`, затем измените `hours` и добавьте ключ `completed` со значением `False`. Создайте из `title` и `hours` кортеж, распакуйте его в две переменные и выведите. Объясните в README, почему запись удобно представить словарём.

## Проверки

В `test_collections.py` импортируйте функции из `collections_lab.py`. Интерактивный запуск модуля поместите под `if __name__ == "__main__":`.

- `word_counts("Python, python! SQL")` → `{"python": 2, "sql": 1}`; строка `!!!` → `{}`.
- Темы `["python", "sql", "python"]` и `["sql", "git"]`: общие `["sql"]`, все `["git", "python", "sql"]`.
- Один из списков тем пуст: пересечение пусто, объединение содержит уникальные элементы другого списка.
- Сводка примера: `{"основное": 7, "дополнительное": 2}`.
- Поиск `основное` → `["A", "C"]`; `нет` → `[]`; сводка пустого списка → `{}`.
- После вызовов исходные записи равны копии `[record.copy() for record in records]`. Здесь значения записей простые, поэтому такого копирования достаточно.
