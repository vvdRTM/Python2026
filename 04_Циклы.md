## Цель

Выбирать между `for` и `while`, накапливать результат и объяснять завершение цикла. Необходимы работы №1–3.

## Краткая теория

`for` перебирает значения. `range(start, stop, step)` задаёт последовательность целых чисел: `stop` в неё не входит, `step` не может быть нулём. По умолчанию начало равно нулю, шаг равен единице.

```python
# example.py
total = 0
for number in range(1, 5):
    total += number
    print(f"Число: {number}; сумма: {total}")
```

Последовательные значения суммы: `1`, `3`, `6`, `10`. Переменная `total` — накопитель. Счётчик устроен похоже, но обычно увеличивается на единицу.

`while` выполняет тело, пока условие истинно. Для завершения значение, участвующее в условии, должно изменяться либо в теле должен выполняться `break`.

```python
# command_loop.py
command = input("Введите текст или стоп: ")
while command != "стоп":
    print(f"Получено: {command}")
    command = input("Введите текст или стоп: ")
print("Готово")
```

`break` завершает ближайший цикл, `continue` переходит к следующей итерации. Если программа зациклилась, остановите её сочетанием Ctrl+C в терминале или командой остановки среды. Не запускайте бесконечный цикл без понимания способа остановки.

## Обязательные задания

### 1. Диапазон в обе стороны

В `range_numbers.py` введите целые `a`, `b`. Выведите все числа от `a` до `b` включительно: по возрастанию при `a < b`, по убыванию при `a > b`, одно число при равенстве. Вывод по одному числу на строке.

### 2. Статистика потока

В `statistics.py` введите целое `n >= 1`, затем ровно `n` целых чисел. Найдите сумму, число положительных значений и максимум. Список пока не используйте. Максимум можно инициализировать первым введённым значением; инициализация нулём даст неверный ответ для всех отрицательных чисел.

### 3. Повторный ввод

В `positive_input.py` запрашивайте целое число, пока пользователь не введёт положительное. После этого выведите его квадрат и количество отклонённых попыток. Тип `int` гарантируется; проверка текста вместо числа будет в работе №10.

## Проверки

| Задание | Вход | Ожидаемый результат |
|---|---|---|
| Диапазон | `2, 4` | `2`, `3`, `4` |
| Диапазон | `4, 2` | `4`, `3`, `2` |
| Диапазон | `3, 3` | Только `3` |
